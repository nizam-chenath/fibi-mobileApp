# Fibi Backend

Express-based user management API backed by MySQL.

## Getting Started

```bash
cd backend
npm install
npm start
```

Create an `.env` file that provides the MySQL credentials expected by `src/db/mysql.js`:

```
PORT=5000
ACCESS_TOKEN_SECRET=your_jwt_secret
DB_HOST=localhost
DB_PORT=3306
DB_USER=fibi_user
DB_PASSWORD=fibi_password
DB_NAME=fibi_users
```

Ensure the `users` table contains the columns referenced in `src/models/userModel.js` (see file for the complete list).

## API Overview

All routes live under `/api` and respond with JSON.

- `POST /api/login` – authenticate a user and return a JWT access token.
- `POST /api/logout` – mark a user as logged out.
- `GET /api/user-details/:employeeId` – fetch a single user (protected).
- `GET /api/all-users` – list all users (protected).
- `POST /api/update-user/:employeeId` – update a user record (protected).
- `DELETE /api/delete-user/:employeeId` – delete a user record (protected).
- `GET /api/universities` – fetch every record from `teamsquad_universities` (protected).

Authenticated routes require a `Bearer` token generated by the login endpoint.

## Development Notes

- The application now uses `mysql2/promise` pools instead of Mongoose/MongoDB.
- Database helpers are located in `src/models/userModel.js`.
- The connection pool is configured once in `src/db/mysql.js` and shared across the app.
