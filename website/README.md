# Fibi landing (website)

This is a minimal Vite + React landing site for the Fibi app.

Quick start (PowerShell):

```powershell
cd "C:\Users\nizam\fibiHackathon\fibi-mobileApp\website"
npm install
npm run dev
```

Files created:
- `index.html` - app entry
- `src/` - React components and styles
- `public/assets/` - placeholder assets (screenshot + favicon)

Drop your own app screenshot at `public/assets/app-screenshot.svg` or replace with a PNG/JPG named `app-screenshot.png`.
